# OpenSphere AI

**Turning public data into understandable, source-backed insights.**

OpenSphere AI is a data intelligence platform designed to collect, process, store, explore, and analyze real-world data from selected public data sources.

The project aims to bring structured datasets and relevant documents into one platform where users can explore information through interactive visualizations, apply filters, search related reports, and ask questions using an AI assistant that references its underlying sources.

### Core Objectives

- **Data Collection:** Retrieve real-world data from selected public APIs, government portals, and other accessible sources.
- **Data Engineering:** Clean, validate, transform, and organize collected data into a consistent structure.
- **Data Storage:** Store structured datasets and related documents for reliable querying and retrieval.
- **Data Exploration:** Provide searchable datasets, filters, charts, and summaries.
- **AI-Powered Insights:** Use LLMs and Retrieval-Augmented Generation (RAG) to generate answers grounded in available data and documents.
- **Source Transparency:** Link insights to their original sources wherever possible.
- **Extensible Architecture:** Design the system so additional public-data domains can be integrated over time.

### Initial Focus

The first version will focus on public air-quality data, exploring measurements across locations and time periods. The initial scope will expand only after the data collection, storage, and analysis pipeline is working reliably.

### Planned Technology Stack

Python, Flask, SQL databases, Pandas, public APIs, React, data visualization, LLMs, embeddings, and RAG.

### Learning Goals

OpenSphere AI is also a hands-on learning project focused on software development, Git and GitHub, API integration, data engineering, database design, AI application development, testing, and deployment.

*This repository is under active development. Features and technology choices may evolve as the project progresses.*
